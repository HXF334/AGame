# 敌友标记 / 身份显示 规范 (2026-11-10)

> 这份文档锁「敌友钮、身份推断、取牌标志」这三块的**判定口径**。
> 改动前先看这里；改完同步更新这里，并在回复里说明改的是哪一条。

## 1. 敌友钮显示什么

| 观察者与该玩家的关系 | 显示 |
|---|---|
| 关系**确定**(主A 对抓方=敌; 次方亮明/明打后全部按真阵营) | 自动标真实关系 |
| 关系**靠推定得出**(推定出次A -> 他=敌; 其余抓方=友, 裁定 A) | **也自动标**(推定结果) |
| 推不出来(暗打且还没有任何线索) | 「?」 |
| 你**手动标过**(含手动切成问号) | 显示你标的(手动优先, 不被自动判定覆盖) |

### 1V4 暗打
- 1V4 **不**当「阵营公开」处理(历史上误当公开 -> 给所有人标了身份)。
- 只有「对主A」的关系确定: 主A 必是敌。
- **抓方之间 = 不明**(次方身份还没露) -> 不自动标, 只能手动标。

## 2. 手动标记三态
- 循环顺序: **? -> 友 -> 敌 -> ?**。
- 三态存成 friend / enemy / **unknown**(不能用 null: null 表示「没标过」, 会被自动判定覆盖 -> 切不到问号)。
- 手动切成问号 = 明确表示「不明」-> AI 决策也按不明处理(不按推定)。
- 什么时候不能手动改(camp.canManualMark):
  - 次方已亮明 / 明打 -> 所有人不能改(按真实阵营自动)。
  - 自己是次方 -> 不能改(已知全部阵营)。
  - 1V4: 主A持有者不能改(知道其他四家); 四个抓方之间**可以**改(关系不明)。
  - 2V3 暗打且次方未明: 除次方本人外都可以改。

## 3. 身份(次方)怎么推定

推定只在**暗打**且**次方未亮明**时进行; 亮明/明打一律按实际阵营, **不做任何推定**。

| 信号 | 说明 |
|---|---|
| 信号1 | 用**大蛋子+**(大蛋子及以上)压**身份不明**的人 | 那个人是**次方** |
| 信号2 | 用**三个 4 及以上**的 4 去取身份不明的人的牌 | 那个人是**次方** |
| 信号3 | 累计打出过 **2 次及以上「蛋子」**(蛋子/大蛋子/真七/真八) | 那个人是**次方** |
| 抓方推定 | 用**大蛋子+**压了**主A** | 那个人是**抓方**(主方不会压自己人) -> 按阵营给他敌友标记 |

注意: 「2 个及以上的蛋子」= **累计出牌次数**, 不是「一手牌里有 2 组以上同点」
(后者是连珠蛋/假八/大假八, 属于大蛋子+, 已由信号1覆盖)。

## 4. 取牌「取」标志

- 标志绑在「**那一手出牌**被取过」上, **不跟着牌走**。
- 有人被 4 取走 -> 他座位前那手牌的**最后一张**右下角标「取」。
- 同一手牌以后再被打出 -> 新的一手**没有**标志(他一出牌旧标志就清掉)。
- 只有重新打出的那手**又被取** -> 标志重新出现。
- 实现: 引擎状态反查「谁出的这手被取了」-> uiTakenPlay[pid]; 出牌时清; 渲染只标最后一张。
- **禁止**在牌对象上打标记(牌对象是共享引用, 会串到别的牌上 -> 误标)。

## 5. 自查清单(改完必查)

1. 1V4 暗打开局: 抓方之间是「?」, 只有主A 是「敌」。
2. 暗打有线索后: 推定出的次方标「敌」, 其余抓方标「友」。
3. 手动点敌友钮: 能循环到「?」, 且 UI 真的显示「?」(不是被自动判定顶回)。
4. 次方亮明后: 全部按真实阵营, 手动改不动。
5. 被取的牌: 只有那手最后一张有「取」; 再打出后标志消失, 再次被取才再出现。
