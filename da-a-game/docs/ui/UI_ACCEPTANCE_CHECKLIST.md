# UI 画面验收清单（2026-11-10）

> 用途：把历轮界面改动逐条在**微信开发者工具模拟器**上过一遍（D 段 + E 段合计 40+ 项）。
> 无头测试只能证「几何与时序」，**画面好不好看、挤不挤、点不点得到**必须人眼看。
> 勾选方式：把每条的 [ ] 改成 [x]；发现不对就在该条后面写现象 + 截图/日志。

## 0. 怎么跑起来

| 步骤 | 操作 |
|---|---|
| 起模拟器 | AGame/tools/wechat-cli.ps1（微信开发者工具 CLI 的 PowerShell 包装，UTF-8 安全） |
| 项目目录 | AGame/da-a-game（appid wx99808147273cdea1，基础库 2.19.4） |
| 建议分辨率 | 横屏 iPhone SE~Max：667×375 / 812×375 / 844×390 / 926×428 |
| 真人座位 | 随机（顶栏可切换视角），**验收时先用「顶栏切视角」固定到甲**，便于对照 |

> 注意：模拟器里 AI 会**同步抢跑**（无头测试 AI 延迟 0ms，真机 1000ms），
> 所以「等 AI 出牌」这类观察请以**画面最终态**为准，不要按固定秒数判断。

## 反馈格式

报障时带上这三样，我定位最快：

1. **画面截图**（标注哪里不对）
2. **Console 日志**里 [da-a-game] 开头的相关几行（尤其是「PASS / PLAY / 推风 / 倒计时」附近）
3. **当时的局面**：谁出了什么、你的手牌是什么、轮到谁
