### 真人座位（开局随机）
**开局随机**在 A~E 中选一个座位（NAMES_MAP: A=甲 B=乙 C=丙 D=丁 E=戊）。每局重掷。

### 阶段闸门（把自动链拆开）
原来开局是**一条自动跑完**的链：
`START_GAME → FORCED_CHECK → ADVANCE → REVEAL_BOTTOM → CHOOSE_IDENTITY → PLAY → runAI()`，
中间零人工闸门 —— 这就是为什么真人日志里从未出现过亮A选择。

现在按既有状态机（SKILL §3，未新增任何阶段）拆成 6 档：

```
发牌 → [强制排查] → 反A → 翻底牌 → 次方身份 → 出牌
```

- **强制排查**仅在「主A 未确立」时执行（真人亮了 A 就跳过，符合 §4.2）
- **【下】按钮已删除**（2026-10-24 用户要求）：各阶段**自动判断**能否进入下一阶段，能就直接进
- 需要真人决策的阶段会**停下等真人点**，决策完**自动续跑**（不再需要点【下】）
- 真人没有 A 时，**AI 按座位顺序依次尝试亮A**，完成后自动进入下一阶段
- 每个决策函数**先消费 gateChoice 再执行**，防止同一次决策被执行两次
- 引擎拒绝时只记日志，**不改阵营**
- 从发牌到出牌**自动推进**（强制排查 → 反A → 翻底牌 → 次方身份），
  只有需要真人决策的两处会停下：亮A（有A时）与反A/次方身份（有资格时）

### 引擎资格判定纯函数（`src/transition.js` 新增导出）
判据**从既有 handler 提取**，不是另写一套规则：

```
canLiangA         亮A资格（主A未确立 + 阶段正确 + 手牌含A，底牌不算）
canFanA           反A资格（主A已确立 + 反A未发生 + 手牌有2张同花色A）
canChooseIdentity 次方身份资格（授权人判定：次方优先，否则主A确立者）
identityChooser   授权人查询
```

> **注意 `canFanA` 的花色**：SKILL §4.4 原文「任意花色都可以；不要求与当前主A花色相同」。
> 2026-10-24 实测发现初版错把花色限定成主A的花色，导致玩家持别的花色双大A时被判
> 「无反A资格」—— 已修，并由 `tests/test-eligibility-rules.js` 锁住。

### 统一按钮模型（需求八）
按钮集合**完全由游戏状态推导**，单一来源：

```
uiButtons()      按钮集合（id / label / enabled）
uiButtonAt(x,y)  命中判定
uiClick(id)      按 id 分发
```

按钮：亮A·不亮 · 反A·不反 · 公开身份·隐藏身份 · 下 · 出牌·过牌 · 下一局
资格不具备时**仍然显示但 `enabled=false`**。

### 结算画面（需求十）
GAME_END 时画：胜负标题 + 原因 + **五人得分表**（姓名·(你)·阵营·剩余张数·分数增减，增绿减红）。
分数**由引擎 `calculateScore(state, result)` 给出**，UI 不自己算（平局返回 `{}`）。
【下一局】会重置真人座位（**随机重掷**）、清选牌/命中框、清日志、重新发牌并重走闸门。

### UI 日志 + 【Log】开关（需求十一）
右上角【Log】按钮切换，**默认隐藏**。**不影响日志记录**（`logHistory` 一直在记）。
面板显示最近 11 条，含**阶段进出 / 资格判定 / 结果**三类。

### 出牌失败提示（需求十二）

| 情况 | 行为 |

## 3. 本版修的真实 Bug（都有真机/日志证据）

| # | 现象 | 根因 |
|---|---|---|
| 1 | **所有按钮都点不到** | `uiButtonAt()` 调 `uiButtons()` **重新生成了一份对象**，而 `x/y/w/h` 是 draw 时写进**另一份对象**的 → `x >= undefined` 恒 false |
| 2 | **phase=PLAY 但按钮全灰、AI 不出手** | 引擎在 IDENTITY 阶段结束就把 phase 变成 PLAY，而 `currentPlayer` 只在 PLAY 档设置；同时 `uiButtons()` 在 PLAY 阶段**不再显示【下】** → PLAY 档永远到不了（死锁）|
| 3 | **持双大A 却被判「无反A资格」** | `canFanA` 把花色限定成主A的花色，违反 SKILL §4.4「任意花色都可以」|

**Bug 2 有两条路径**，初版只修了其中一条：
- 「不亮A」路径（转换发生在 `runGateStage()` 内）→ 正常
- 「次方身份选择」路径（转换发生在 `humanChooseIdentity()` **内部**）→ 死锁

修法：抽出统一入口 `enterPlayIfNeeded()`（设首出权 + 触发 AI），在 5 处都调用。

## v0.33.0（2026-11-01）· 全量回归首次跑完 → 修复 2 处本批引入的回归

**上一版**：v0.32.0（2026-10-30）

**背景**：上一批（45712e1 / 30d3141）改了 `src/combos.js` 的连段枚举和 `game.js` 的空选牌行为，但**没跑全量回归**。本轮首次跑全量（**65 套件**）暴露 2 个失败。基线对照（`git worktree` 建 `8e423ac`）两个测试都全绿 → 确认是本批引入。

### 根因 1：连段枚举写死「每点数取一张」→ 双龙/连珠蛋枚举不到

- 2026-10-27 把「同点数的所有牌塞进同一段」改成「每点数各取一张」，修好了 `[9,10,J]` 被 `[8,9,9,10,10,J]` 污染的问题（引擎判 INVALID，真正能压桌面的连张从没被枚举过）。
- **但**：双龙（每点 2 张）、连珠蛋（每点 3 张）从此**再也枚举不到** → AI 起手只会出单连张。`test-ai-lead-combo.js` 1.3「手上有 5-5-6-6-7-7 双龙 → 起手出双龙」实得 `STRAIGHT`。
- **修法**：同一连续段内，每个点数取**相同张数 k**（k=1 连张 / k=2 双龙 / k=3 连珠蛋）。混合张数天然枚举不出来，且每种张数都覆盖到。

### 根因 2：e2e 用 `doPlay()` 不带牌驱动真人席位 → 永不出牌

- 2026-10-27 起 `doPlay()` 不再自动替玩家出牌（没选牌 → 弹「请先选牌」），这是**用户要求的**正确行为。
- `test-pushwind-human-e2e.js` 仍用裸 `g.doPlay()` 驱动真人席位 → 一张牌都没出 → 真人席位永不出牌 → 循环到 guard → **6 局未结束 / 6 局卡死 / 推风 0 次**。
- **修法**：e2e 改走和人手一样的路径 —— `uiHint()` 选一个**引擎认可**的候选 → `doPlay()`（`uiHint()` 内部用引擎 transition 逐个校验，选中的候选一定能出出去）。

### 证据

- 全量回归：**65/65 passed**（修复前 63/65）
- 变异测试：`combos.js` 退回 k=1 → 1.3 **精确失败**（8|7|1）；e2e 退回裸 `doPlay()` → **6 条断言精确失败**（不是全挂）；还原后复跑全绿。
- 提交：`d785da7`

## v0.32.0（2026-10-30）· 真机验收修 UI + 引擎候选枚举修复

**上一版**：v0.31.0（2026-10-26）

### 修掉的 Bug（全部来自用户真机截图）
1. **【提示】选不到能压 567 的连张** —— 根因在 src/combos.js 的连段枚举：它把同点数的**所有**牌塞进同一段，手里 9 有两张时枚举出 [8,9,9,10,10,J] 这种含重复点数的组合，identifyHand 判 INVALID，于是真正能压的 [9,10,J] **从没被枚举过**。引擎 identifyHand/canBeat 一直是对的，漏的只是候选枚举 → 【提示】/ AI 选牌 / doPlay 组合回退三条路径共用一个函数，一处修全线好。
2. **【提示】选不到「双大王」** —— 同类：王组合只生成 1大1小/2大1小/1大2小，从没生成过 2 大王（SKILL L189「双王 = 任意2张王」）。现在枚举所有 2/3/4 张王的组合。
3. **选一张牌自动补成最小可用牌型**（选 9 → 自动选中 8 9 10），判据=引擎认可的候选里取张数最少、同张数牌力最小且含该牌。
4. **过牌的人显示「不出」而不是旧牌** —— PASS 无条件清掉该玩家的出牌显示（不再依赖轮次判定）。
5. **轮末：已出完牌的人桌面清干净 + 提示「已出完」**；轮末**不清**「不出」文字。
6. **亮A 阶段改成花色按钮**（4 个花色，手里没有的置灰）+ **5 秒倒计时**，到点自动跳过亮A进强制排查；「不亮」按钮取消。
7. **记牌器默认展开**。
8. **结算画面**：标题带加高（离明细远一点）+ 整体下移；积分带「分」字，头像下正分不带加号。
9. **提示条移到屏幕正中**；**没选中牌点【出牌】弹「请先选牌」**，不再自动替他出一张。
10. **左右安全边距 6% → 3.5%**；**双大A 右侧玩家第 2 个角标画在第 1 个左侧**。
